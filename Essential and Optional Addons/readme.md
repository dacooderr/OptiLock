## BareEssentials and BareEssentialsBS are a collection of essential fixes for Deadlock when using FPS configs and modifying your gameinfo.gi and video.txt. If you want to use these mods without Deadlock Mod Manager, you will have to manually add them to your addons folder in game/citadel/addons and rename the vpk file to pak02_dir.vpk or any higher number. (ex. pak43_dir, etc.)
 **Mods Included:**
 
	- Black Skybox (BareEssentialsBS Only)

    - Vindicta Scope Downscale

    - Optimized Soul Containers

    - Sinner's Light Fix 

    - 4:3 Fix
