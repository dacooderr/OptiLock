# FAQ

- "Як я моу знайти параметр в config"  
Натисніть ctrl+f в текстовому редакторі та вводом бажаного параметра для змінення.  

- "Як повернутися до стандартних налащтувань"  
Повністю прибрати всі параметри - найшвидший спосіб 

- "Як змінити fov (Поле зрору)"
``r_aspectratio``
``citadel_camera_hero_fov``
 	+ Налаштування двох значень під себе.  

- "Конфіг зламається після патча"  
Файл gameinfo.gi переписується в деяких патчах, навіть якщо патч був мінорний. В такому випадку просто замініть вище вказаний файл повторно.

- "Ігра крашиться"
Необхідно повністя видалити ВСІ файли гри (після видалення за допомогою стіма вручну видалить залишкові файли). (встановлення модів що замінюють файлт гри приводить до того що стім їх не бачить і потрібно видаляти самому).
Будьте певнеми в тому що видалиди всі файли Deadlock **ПОВНІСТЮ** - [Приклад](https://media.discordapp.net/attachments/1494139617090469980/1494139617249726535/delete.jpg?ex=6a1052b4&is=6a0f0134&hm=0fda70acb60a96ed746ed56c0817f357298c2fbec4b05b678b6cab25e54f09dc&=&format=webp)
